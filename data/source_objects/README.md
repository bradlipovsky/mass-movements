# Frozen audit source objects

These are exact source files retained for the climate-blind event audit. Their
paths and SHA-256 checksums are registered in `data/event_audit/sources.csv`.

Copyright and reuse terms remain source-specific; inclusion here does not put
an object under any project-wide license. Most frozen papers are CC BY, agency
objects are public domain or carry the license named in the source table, and
`buntgen2025.pdf` is an unmodified CC BY-NC-ND version of record. Consult the
source table and original license before reuse.
